# وردي | Wirdi

An Islamic lifestyle application built with Flutter.

## Features (Coming Soon)

- 📖 Quran Reading & Audio
- 🕌 Prayer Times
- 📿 Digital Tasbeeh
- 🤲 Daily Azkar
- 📊 Khatma Tracker

## Tech Stack

- **State Management**: Riverpod
- **DI**: GetIt
- **Database**: Hive
- **Network**: Dio + Retrofit
- **Audio**: just_audio
- **Location**: Geolocator
- **Theming**: Custom with light/dark mode
